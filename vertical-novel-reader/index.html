如果导入的是从竖排 PDF 复制出来的乱序文字（每行只有几个字、要横着连起来读）：

使用说明：
1. 点击左上「导入小说」选择竖版/横版 txt。
2. 本站默认以横版（从左到右）显示，自动把竖排版式转成横排。
3. 右侧面板可调背景、字色、字号、行高、字体，还能贴字体链接导入新字体。
4. 右下角可上一章 / 下一章，左侧是仿起点网文目录。

-

🎨 阅读样式

支持两种：① Google Fonts / 字体 CSS 链接（如 https://fonts.googleapis.com/css2?family=ZCOOL+XiaoWei ）② 字体文件直链（.woff2/.woff/.ttf/.otf）。填好字体名后在上面选“自定义”即可生效。
